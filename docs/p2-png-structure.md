# P2 PNG 结构校验与异常恢复

2026-10-16，对应 P2-01 内容校验和 P2-06 动画格式明确拒绝。

依据 [W3C PNG 第三版](https://www.w3.org/TR/png-3/) 的 IHDR、PLTE、IDAT 与块命名规则，补齐 CRC 之外的结构检查：

- IHDR 只能位于开头且只有一份；校验颜色类型/位深组合、压缩、过滤和交错方法。
- IDAT 必须连续，允许连续空块，但总数据不能为空。
- 索引色必须先有调色板；调色板不能重复、迟到、为空、长度不为 3 的倍数或超过位深容量；灰度类型不能有调色板。
- 拒绝未知关键块、非法块名和保留位不符合当前规范的块名。
- acTL、fcTL、fdAT 均明确拒绝，即使缺少动画声明，也不能作为静态 PNG 上传。

保持已有 CRC、EXIF、XMP 和 Live Photo 检查，原图字节不变。错误通过 assetData 返回原因和重新导出静态原图的操作要求。无数据库迁移；历史修复共用此检查器，不会自动删除资产。

## 回归

24 个固定用例：21 个异常结构，随后 3 个正常上传（原静态 PNG、含连续空 IDAT 的合法拆分、1 位索引色）。成功样本由 Pillow 独立解码验证；均为合成样本，不计入真实图库验收。Worker/D1/R2 回归检查拒绝项无资产、无预约、无孤儿对象，随后正常项上传、去重、原图字节与 Sync/ACK 成功。原有真实私有 PNG/XMP、Live Photo 与 reset/ACK 回归继续运行。

公网验证：`node scripts/png-structure-probe.mjs`，固定使用 dev，保留可去重合成图片；以错误校验和的重复 IHDR 样本检查新版本生效，避免旧版本保存异常探针。

## 边界与剩余任务

这是有界容器校验，不解压 IDAT，不验证滤波后的扫描线、调色板索引值或全部辅助块语义；结构通过不等于所有像素可解码。未扩大支持格式，也未实现完整 PNG 解码器。
