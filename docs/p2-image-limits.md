# P2 手机尺寸原图与像素上限评估

日期：2026-10-18；仅 dev 分支本机开发。本轮不部署，不执行远程迁移。CPU 超预算继续暂缓，G1 未通过。

## 当前范围与决策

静态 JPEG/PNG 上限调整为 **64,000,000 像素、宽高各不超过 16,384**。单文件 **4 MiB**、multipart 请求体 **4 MiB + 64 KiB**、每账户 20 张逻辑额度不变。超过像素/边长返回 400，超字节返回 413；结构化错误指向 assetData，并说明具体限制及缩小/压缩要求。

| 编码尺寸               | 总像素     | 新像素范围 |
| ---------------------- | ---------- | ---------- |
| 4032×3024              | 12,192,768 | 支持       |
| 4208×3120              | 13,128,960 | 支持       |
| 8064×6048              | 48,771,072 | 支持       |
| 8192×6144              | 50,331,648 | 支持       |
| 8000×8000 / 16000×4000 | 64,000,000 | 边界支持   |
| 8000×8001              | 64,008,000 | 拒绝       |
| 16385×1                | 16,385     | 超边长拒绝 |

表中支持仅指像素范围，仍须同时满足字节、容器、EXIF、XMP 和 Live Photo 等既有检查；不保证所有手机原件或所有元数据可用。HEIC、视频及 Live Photo 仍不支持。16384 的边长允许部分长图，同时避免仅靠总像素放行极端细长图片；6400 万像素覆盖上述 1200～5000 万像素尺寸，保留有限上限，不扩展至任意分辨率。

## 为什么可以调整与风险

代码检查上传、读取和修复链路：imageHeader 遍历已受字节限制的容器与元数据；没有完整 JPEG/PNG 像素解码，也不生成缩略图。原图和预览继续读取同一原始对象，历史方向修复也使用相同图片检查器。提高图片头允许的尺寸不会新增按 width×height 分配的服务端像素缓冲区；但文件复杂度、现有元数据解析与同步仍有成本，不能据此证明 CPU 免费额度达标。

完整 RGBA 解码时 64,000,000 像素单份约 244 MiB，还可能有额外工作缓冲。当前这一成本主要由查看图片的客户端承担；iOS 预览耗时、内存压力和后台行为仍需真机验证。未来如添加服务端解码/缩略图，须重新评估此上限与并发预算，不能沿用本轮有界容器检查结论。

Worker 与本机清单验证共用 image-limits.ts；清单支持项独立尺寸范围同步提高，并增加总像素限制，防止工具仍以旧边长拒绝图片或接受业务必拒绝的支持项。清单期望值仍须独立确认，不能从服务端响应反填。

Live Photo EXIF、XMP 保守允许列表、设备动态请求防护、4 MiB multipart 流量边界、bcrypt cost 12、会话鉴权、reset/ACK 状态机均未改动。不改原图字节、不剥元数据、不自动删除/修复历史资产或预约；无需数据库迁移。此前按用户授权删除的样本不能通过本次代码变更恢复，可在保留的源原件中重新准备测试副本。

## 本机验证与证据边界

新增回归覆盖 JPEG/PNG 的旧上限以上尺寸、6400 万像素精确边界、边长边界与超限、零尺寸、PNG 超大整数、EXIF 方向 6/8 布局交换、重复上传同 ID、原图/当前预览字节不变，以及完整和 reset:true 快照的尺寸、ACK 后空增量。高像素 Live Photo/XMP 拒绝与超限拒绝后核对资产、预约、引用和本地存储未变，随后正常上传可恢复；另覆盖高像素 PNG 在 4 MiB 精确边界成功、超过 1 字节返回 413。

边界回归采用明确标注的“仅改图片头”合成结构变体，不能当作可解码真实图片。另使用 Windows System.Drawing 实际编码生成 8064×6048 JPEG/PNG、8192×6144 JPEG（均低于 4 MiB），独立读取尺寸后运行本机真实入口的隔离 D1/R2 完整验收；这三张是合成素材，不计入真实照片数量。

[高像素实际编码素材本机报告](contracts/p2-large-pixel-local-smoke.json)记录上传、重传同 ID、原图与当前预览逐字节回读、实际 MIME、独立布局、Sync/ACK、空增量及退出。没有私人公网上传，也没有以本机结果替代官方 iOS 显示、真实混合备份队列、完整像素/色彩验证或 G1。
