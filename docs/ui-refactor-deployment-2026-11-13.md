## 观察与边界

一次生产只读 JavaScript 下载超时，经有界 GET 重试后取得完整文件并通过 SHA-256 校验。网络检查保留证书验证，使用现有本机代理及默认 TLS 协商；仅在连接尚未发送 HTTP 请求时重试写方法，没有修改系统网络配置或应用代码。

手机布局检查使用 Chromium 视口模拟；真实 iPhone Safari、官方 App 真机、Live Photo 播放/恢复、真实规模和整库灾备仍按此前独立关口验收。截图可能包含私人图库内容，仅保存在本机忽略目录，Git 中只保存脱敏结果。
