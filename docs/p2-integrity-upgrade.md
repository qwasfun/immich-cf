# P2 历史资产原生摘要升级与恢复

## 范围与决策

为历史 JPEG/PNG 资产补齐原生 SHA-1 证明，不重新编码图片、不修改官方 App。默认预检只读，显式 apply 才执行。一次最多处理一张 4 MiB 资产；图库批次按顺序执行。旧原图、上传预约及同步检查点均保留。CPU 超预算继续暂缓，本轮不是 Free/G1 资源关口通过证明。

采用新副本切换引用，而不覆盖历史原图。成功后新增至多一份等大的校验副本，旧原图继续占用 R2 空间，逻辑图片名额不加倍。失败及并发留下的副本也保留，不自动清理；自动 GC 仍是后续单独验收项。

## 契约与提交边界

`POST /api/immich-cf/upgrade-integrity` 使用现有会话认证、账户隔离和实验入口开关，仅接受 id 与可选布尔 apply。省略 apply 或 false 为预检；字段不合规返回字段名称、原因和修正要求，无权访问或不存在统一 404。响应不暴露存储路径、摘要、原始异常或凭据。

1. 读取当前账户资产；检查 1 字节至 4 MiB 限额，读取原图并验证真实字节长度、重新计算 SHA-1，与 D1 的既有 checksum 比较。缺失、超限、损坏一律 409，不写副本或修改资产。存储/事务异常 503，重试同一资产。
2. 预检到此结束。apply 时使用账户/资产/摘要派生的固定副本路径，条件创建（etagDoesNotMatch:*），原生 sha1 校验写入，保留 HTTP/custom 元数据和 storageClass。并发创建返回 null 时重新 HEAD，必须确认大小和原生摘要；未发布的异常副本不会被覆盖。
3. 一条 D1 UPDATE 原子设置 object_key、r2_sha1_verified=1 和 integrity_source_key。CAS 比较旧路径、摘要、字节数、同步游标、旧标记和旧源引用，并在事务执行时复核会话有效、未过期及账户未禁用。冲突 409，保留所有对象和预约。
4. 迁移 0013 仅新增可空源路径字段，既有数据、同步时钟和预约不变。升级不修改客户端可见资产内容、ID、尺寸或同步游标，因此 ACK 后增量保持空；原图/缩略图接口通过新引用读取相同字节。

副本提交后、D1 提交前失败：旧引用可用，重试复用同一副本；D1 提交后响应丢失：重试确认原生摘要后幂等成功。升级与恢复均不删除原图或预约。

## 后续恢复

integrity_source_key 与新引用一起持久化，避免只留对象却丢失恢复来源。已验证副本正常时直接返回 alreadyVerified，不重读或改写；若副本缺失/摘要异常且存在独立源引用，重新完整核对保留原图，再预检或 apply 恢复副本。恢复缺失副本使用条件创建；替换损坏副本使用其当前 ETag 条件写入，不能覆盖并发版本。原生摘要再次验证后执行带会话与资产 CAS 的提交确认。

原图备份缺失或摘要错误时拒绝恢复。没有历史源引用的已验证资产也不会静默降级，仍需通过已有同图重传路径恢复。r2_sha1_verified 不回退为 0；媒体接口始终保持严格原生摘要要求。

R2 与 D1 之间没有跨服务事务，外部删除/修改仍可能在检查后发生；读取接口继续 fail closed，保留源引用供后续恢复。不可根据失败观察删除对象。本方案不能替代全图解码、独立备份或对恶意 SHA-1 碰撞的防护；密码仍保持既有 bcrypt 安全参数。

## 官方资料核实

2026-10-17 核对 [Cloudflare R2 Workers API](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)：put 支持条件操作和 sha1，条件不满足返回 null，指定的摘要可由 checksums 读取。实际本地 R2 回归覆盖条件创建竞争和恢复写入。公网仅验证正常升级与字节一致，不故意损坏远程原图或注入并发删除。

## 本机工具与回归

`node scripts/integrity-upgrade-probe.mjs` 默认预检一条历史资产；`--apply --limit 20` 顺序升级至多 20 条。固定 dev URL 与已确认代理 127.0.0.1:7890，curl HTTP/1.1 + TLS 1.2，证书校验开启；凭据从忽略的 work/dev-account.json 读取。单请求最多 3 次、每次 20 秒、总预算 60 秒；只重试可恢复传输错误和 502/503/504，不重试 400/401/409/证书错误。登录不自动重试，避免制造不确定会话。读取后核对 D1 摘要，升级后复用有界 Range 恢复逐字节比较；报告只保留大小、状态与脱敏传输指标，不落盘照片内容。

本地覆盖：预检零写入、旧原图/预约/元数据保留、幂等、Sync 游标不变、源缺失与等长损坏、异常目标和条件创建竞争、R2/事务失败及响应丢失、并发 CAS、会话撤销/过期、账户隔离与字段错误、4 MiB 边界、副本缺失/损坏恢复和坏源拒绝。完整套件继续执行密码、Live Photo 和 reset/ACK 并发隔离回归。

Go：本机与 dev 的逐项预检及安全升级。No-Go：自动删除旧原图/预约、跳过摘要校验、降低密码或同步隔离要求、宣称真实 iOS 混合队列/100 张照片/CPU 关口完成。若回退 Worker，保留 0013 和原生摘要标记；旧版本仍读取既有 object_key，不回退到未知原图或清除源路径。
