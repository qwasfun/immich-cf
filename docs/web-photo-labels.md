# Web 照片标签与评分

## 设置标签和评分

照片大图提供“标签与评分”，照片墙选择栏支持批量设置 1～1000 张。单张窗口读取当前标签与评分；批量窗口显示共有标签及评分是否混合，默认追加标签、不修改评分。

标签支持追加、移除指定项、替换全部和清空。替换或清空会明确说明覆盖范围；保存时会处理尚未点击“添加”的输入。每张最多 20 个平面标签，每项 1～32 个 Unicode 字符，不含换行或控制字符。名称先做 NFKC 规范化并去掉首尾空白，ASCII 字母不区分大小写去重；同义拼写不会重复追加。标签中的逗号、斜杠和百分号均按名称原文处理，不作为分隔符或层级。

评分为 1～5 星，可以清除为“未评分”；0 不是评分值。选择“不修改评分”只处理标签，单独设置评分也不会覆盖标签。卡片显示已评分星级，大图详情显示标签和评分。

任一照片追加后超过 20 项，或存在越权、已删除/隐藏项目、会话失效、版本冲突，整批拒绝。失败保留选择和窗口输入；409/503 需要刷新并重新读取，窗口明确提示会重置输入。不会自动重发不确定的追加/替换操作。

## 筛选与浏览

原有查找表单新增标签与评分：一个标签精确匹配，可组合“仅 N 星”“N 星及以上”或“未评分”，并与文件名、日期、类型、排序共同使用。搜索覆盖当前范围全部照片；相册、收藏、归档、回收站和相册选图均使用同一规则。主照片页按文件名、标签或评分查找时，也包含匹配的归档照片。

标签输入提供本人已用标签建议，每次最多 50 项，继续输入可查找其他名称；目录不会返回其他账号或已删除照片的标签。标签和评分条件绑定分页游标、年月统计、定位与刷新/返回位置恢复；切换条件清空选择。修改后不再匹配条件的照片会离开当前结果，可重置筛选找回。

## 接口与数据保持

| 接口                                     | 用途                                                                                                 |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| POST `/api/immich-cf/web/labels/inspect` | 同源提交 `ids`，返回数量、共有标签、评分/混合状态和 `version`                                        |
| PATCH `/api/immich-cf/web/labels`        | `ids/version`，可选 `tagAction=add/remove/replace/clear`、`tags` 和 `rating`；`rating=null` 清除评分 |
| GET `/api/immich-cf/web/tags?q=…`        | 本人标签建议、使用照片数量及是否有更多，最多返回 50 项                                               |

照片与年月接口新增 `tag`、`rating` 参数。`rating=all/none/1…5/gte1…gte5`，`tag` 为规范化后精确名称；无效字段返回明确路径、原因和修正要求，不回显提交值。成功修改返回 `processed/changed/unchanged`，无变化不增加版本。

迁移 `0037_photo_labels.sql` 新增标签 JSON、评分、索引与事务守卫；索引随标签更新或照片永久删除自动维护。保存按批读取当前资料、校验版本，在一个 D1 事务中完成全部写入；中途失败回滚标签、评分、索引与同步版本。

拍摄时间、归档、收藏、相册、Live Photo 配对、原件字节与摘要及 App 私有元数据保持；删除恢复保留标签评分。已有分享继续生效，访客响应不暴露本人标签与评分。账号导出保留这两项资料。

Web 标签采用独立的平面标签，不宣称支持官方标签层级、标签管理端点或官方 App 标签同步。评分沿用冻结 EXIF 的 1～5/null 字段，初始/增量和相册 EXIF Sync 包含评分；清除后也发送 null，避免其他客户端残留旧评分。官方 App 真机行为仍须独立验收。
