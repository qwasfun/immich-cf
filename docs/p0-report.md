## 影响架构的结论

1. **iOS Cookie 鉴权不可遗漏。** 原生层将登录令牌写入共享 Cookie；仅实现 Bearer 不足。撤销、恢复、后台任务和媒体读取必须一致。
2. **版本决定协议面。** 报告 3.3.1 会请求 22 个同步家族，包括非产品目标。不能只返回版本号再逐步补协议，不能假设 features=false 停止所有请求。
3. **Sync 有状态且涉及关系。** 检查点按 session/type 保存，更新和删除游标不同，backfill 有双 ID，完成上界使用 UUIDv7。D1 需要变更审计与事务设计。
4. **上传沿官方 multipart 协议。** Worker 接收 `/api/assets` 后写 R2；不能要求 App 使用自定义预签名上传流程。重复检查、响应 id 与后续同步共同决定备份状态。
5. **大文件可不支持，但提示存在硬边界。** 前台 413 使用固定英文提示；后台配置 retries=3，实际失败调度待实机确认。若该体验不可接受，不能通过修改 App 规避硬约束。
6. **实时更新使用 Socket.IO。** 路径 `/api/socket.io`、websocket transport；普通 WebSocket 不等价。手动同步是否满足核心闭环必须实测；必要时实现握手和相关事件。
7. **免费优先不是已验证性能结论。** multipart、校验和、预览、D1 读写放大与同步时长必须测量。已有部署不等于业务配额或账单验收。

## Go / No-Go

| 关口            | 决定           | 条件                                                       |
| --------------- | -------------- | ---------------------------------------------------------- |
| 源码契约冻结    | Go             | 固定 SHA/OpenAPI/镜像元数据可追溯，本次达到                |
| G0 有限技术验证 | Conditional Go | 可做最小登录/Cookie/空库 Sync 原型，不扩大平台承诺         |
| P0 整体退出     | 未通过         | 参考环境运行、安装构建记录、真实关键路径夹具与降级验证完成 |
| G1/G2/G3        | 未运行         | 按原需求逐阶段验收                                         |

No-Go 触发条件：核心闭环被证实必须改 App 或使用自定义上传协议；认可预算内无法提供必需预览或同步一致性；无法确保权限隔离/失败恢复；大文件失败导致不可恢复核心阻塞。目前没有运行证据证明这些条件已触发或已排除。

优先风险：Cookie/会话、Sync 完整性与版本能力；其次为 iOS 后台备份、HEIC/视频预览、Socket.IO、免费 CPU/D1 放大；持续风险为 App 自动升级。升级必须另做版本差分，不覆盖旧冻结记录。
