# Web 照片地图

侧栏“照片地图”展示有有效 GPS 的照片。默认“全部照片（含归档）”，可切换照片、收藏、归档或个人相册，并组合文件名、拍摄日期、类型、标签、评分和排序。地图汇总完整筛选结果，涵盖尚未加载到照片墙的照片；回收站和隐藏的 Live Photo MOV 不单独进入地图。

拖动地图或使用 + / −、双指缩放，可以查看其他区域。聚合标记显示照片数量，点击后可查看预览、坐标、放大此位置或浏览该位置的照片；“查看此区域的照片”则浏览当前地图窗口内的全部有效照片。区域照片继续复用 60 张双向分页、年月定位、大图、批量选择及照片管理，筛选不能扩大到该区域以外。照片按有效位置归属，不以文件名或拍摄城市猜测地址。

“显示全部位置”缩放到当前筛选的 GPS 范围。地图会按缩放聚合，最多返回 512 个标记，超出时降低聚合精度，仍保持完整计数。支持零度坐标、跨日期变更线、正负 180° 等价位置及高精度坐标。底图采用 Web Mercator，极点显示在投影边缘，原始 GPS 值与查询范围保持。照片 GPS 按原有 WGS84 经纬度处理，不做偏移转换。

地图中心、缩放、范围及筛选按账号和历史条目保存，同标签页刷新或返回时恢复。退出或换账号时清除；禁用标签页存储时仍可浏览，但地图位置不会跨页面保留。区域深链接含位置范围和相册范围，可刷新或直接打开；每次仍校验当前账号。年份/日期时间线的位置记录继续按区域、范围和筛选隔离，关闭大图、返回和刷新恢复可见照片。

## GPS 与原件保持

服务端使用已保存的照片资料：手动位置修正优先于原件 EXIF；显式清空 GPS 后不会回退到原件位置。只有同时具备有效数值纬度 -90～90、经度 -180～180 的照片进入地图，缺少一项、文本坐标或越界值不会当成零。修改位置、清除、归档、删除恢复都会随图库版本更新，原件不重写，收藏、标签评分及相册关系保留。

旧照片尚未读取 EXIF 时，可在照片资料中“读取原件信息”或手动补填经纬度。地图不会为扫描 GPS 批量下载原件，不调用外部地址搜索、逆地理编码或浏览器当前位置。

## 接口与权限

- 新增 `GET /api/immich-cf/web/map`。复用已有筛选参数，`mapView=library|photos|favorites|archive|album` 指定来源，默认 library；相册来源必须提供 `albumId`。`bounds=南纬度,西经度,北纬度,东经度` 可限定当前窗口，西经度大于东经度表示跨日期变更线，`zoom=0..19` 决定聚合精度。
- 返回 `version/total/visible/extent/zoom/clusters`：完整筛选下 GPS 数量、窗口数量、完整 GPS 范围、实际聚合级别及聚合位置/数量/封面 ID/范围；没有文件名清单、对象键或凭据。仅查询 ID 和有效坐标字段，服务端聚合后返回有限标记。
- 现有 `/web/assets` 与 `/web/timeline` 支持 `view=map&mapView=...&bounds=...`，继续复用账号、相册、过滤、锚点和图库版本校验。游标另绑定位置来源和范围，不可跨位置、账号、筛选或版本复用；位置修改后围绕原可见照片重新定位到有效照片。
- 所有地图数据都需有效会话，返回前复核，响应 `no-store`；无效字段返回可定位的具体错误。照片来源中搜索包含归档的规则与现有照片墙一致；其余范围不因地图放宽。

本轮无需新增数据库迁移，不改变官方 App 契约、Sync 或原件生命周期；不实现官方地图端点或 App 地图设置。

## 底图与外部请求

使用打包在本站的 [Leaflet 1.9.4 稳定版](https://leafletjs.com/reference-1.9.4.html) 和 [OpenStreetMap 标准瓦片](https://operations.osmfoundation.org/policies/tiles/)。遵守可见署名、HTTPS、浏览器缓存及有效来源要求，只请求当前可见区域，不提供离线瓦片或批量预取。地图脚本在打开地图时按需加载，图片不经 Worker 转发。

页面说明底图服务会收到当前可见区域的瓦片请求和正常网络信息；请求不附加本站 Cookie、Bearer、照片文件名或照片 ID，来源只发送站点 origin。“显示底图”可关闭外部瓦片，仍可使用位置标记和照片列表；底图失败时明确提示并支持重试。瓦片服务是尽力提供，不能把第三方底图可用性视为本站原件可用性。

私有 SPA 页面仅增加 `img-src https://tile.openstreetmap.org`，不扩大脚本或连接权限；分享页面的 CSP 保持仅本站图片与 blob/data，不开放地图数据。真实手机触控、iPhone Safari 和第三方底图在不同网络下的可用性需分别验证。
