# Web 相册整理

## 相册查找与排序

相册页可按名称或描述即时查找，忽略 ASCII 字母大小写。当前账号最多 100 本个人相册一次完整读取，搜索覆盖全部相册；空结果提示调整条件或重置。默认按最近更新排序，也可按最近创建、名称顺序或照片数量从多到少排序。名称采用中文自然顺序，同名相册用 ID 稳定排序。点击封面或名称都可打开相册。

## 复制与移动

照片、收藏及大图中的“加入相册”会打开可搜索的目标相册列表。个人相册的选择栏和大图另外提供“复制到相册”和“移动到相册”。每次处理明确选择的 1～1000 张照片，不自动扩大到未选择的项目。

- 复制只增加目标关系，保留来源及其他相册关系。
- 移动先加入目标，再从当前来源移出；整批在同一 D1 事务提交，失败不会部分完成。不改变其他相册关系，也不删除图库照片。
- 目标已包含的照片不重复添加，结果提示新增和已有数量；移动时这些照片仍会移出来源。
- 目标列表排除来源相册，必须明确选择目标再确认。相册分享的内容会随照片关系更新，面板中有提示。
- 搜索目标只改变候选显示，已选目标仍明确显示。取消或失败保留原选择；成功移动后清除已完成的选择并刷新来源。

目标列表同时返回本人图库/相册版本。提交时在数据库事务中复核会话、账号状态、两个相册归属、全部照片的可访问性及来源关系。回收站项目或隐藏 MOV 不能单独整理；Live Photo 以照片主体操作，配套原件与关联保持。版本变化返回 409，需刷新目标列表并核对后重新提交；传输/服务端结果不确定时不自动重发移动。

移动来源封面时，既有相册触发器会选取剩余照片作为封面；空相册清空封面。关系和封面继续使用既有官方 Sync 日志与版本，不创建另一套同步数据。

## 快捷封面

在个人相册大图中点击“设为封面”，当前照片立即成为该相册封面；当前封面显示“已是封面”。照片墙原有单张选择设封面入口保留。其他账号、图库外照片不能设为当前相册封面。

## 新 Web 接口

| 接口                                     | 用途                                                                                                     |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| GET `/api/immich-cf/web/albums`          | 本人完整相册列表和 `version`；包含原有相册 DTO 的创建/更新时间、数量、封面，不接受查询参数               |
| POST `/api/immich-cf/web/album-transfer` | 同源 JSON：`ids`、`targetAlbumId`、`mode=copy/move`、`version`；`sourceAlbumId` 在移动时必填，复制时可选 |

成功返回 `processed/added/alreadyPresent/removed` 数量。失败返回具体字段路径和修正要求，不回显提交值。来源或目标不存在/越权返回 404，版本冲突 409，会话失效 401，请求来源无效 403。未知字段、无效方式/ID、空选择或超过 1000 项返回 400。

迁移 `0035_web_album_transfer.sql` 仅新增临时事务守卫表和校验触发器，事务结束即清除守卫；不复制、修改或重编码原件。官方个人相册接口保持冻结行为。
