# P2 异常原图读取保护与恢复

2026-10-16，对应 P2-02 跨存储恢复和 P2-03 媒体原图校验。

## 行为

继备份预检查允许缺失/大小异常原图重传后，媒体端也在 R2 HEAD 返回后对照 D1 的原图字节数。大小不符返回 503 和保留本机原件、重新上传的提示；不返回图片数据、ETag 或 Content-Range。此检查早于 HEAD 成功、304 和 Range 分支，原图、缩略图及预览共用保护。会话和归属检查仍在最前面。

HEAD 与 GET 之间对象被替换/删除继续使用已有 ETag 条件保护，返回 503。没有新增 R2 调用或数据库迁移，未改变密码校验、官方 App 或 reset/ACK。

## 回归与边界

本地 Worker/D1/R2 测试覆盖实际删除/截短原图，分别检查 original、thumbnail、preview 的普通 GET、Range、If-None-Match 与 HEAD 都不误报成功；跨账户依然 404。测试入口注入 HEAD 失败、GET 失败、HEAD/GET 之间替换和删除。随后上传同一图片，完整/范围读取及 304 恢复，D1 行/资产 ID/同步版本不变，只有一个 R2 对象且无新增上传意图，Sync/ACK 正常。

线上仅运行正常媒体读取、范围、HEAD、304、416、退出后拒绝及上传预检查/同步探针，不破坏 dev 原图。故障恢复证据来自本地绑定测试，不等于线上故障或真机恢复验证。

大小一致不能排除等长内容损坏；此改动不是全量内容哈希审计。条件请求之后的存储变化与响应流中途断开仍受客户端重试影响。原图继续充当有界小图片预览，不声称已生成缩略图或完整解码图片。

CPU 超预算继续暂缓，未新增预算实测。P2/G1 的混合备份队列、失败重试与真实图库真机验收仍未完成。test/生产不发布。
