# 网页版 V1：需求、使用与接口

## 产品范围

中文、适配电脑与手机的私人图库，复用官方 App 使用的账号和数据。导航包含照片、收藏、归档、个人相册、回收站、分享管理和账号设置，运维管理员另有账号管理入口。支持浏览器上传、批量下载和照片分享。暂不提供公开注册、照片编辑、地图、人脸识别或视频转码。

网页地址为 dev Worker 根地址：<https://immich-cf-api-dev.fun.workers.dev/>。首次进入使用已有邮箱和密码登录；刷新页面保持 Cookie 会话，退出后不再访问私有媒体。App 服务器地址保持根地址不变。

照片墙按拍摄时刻倒序、相同时按 ID 排序，并按浏览器本地日期分组；回收站按删除时刻排列。每页默认 60 项、最多 100 项。缩略图仅在接近可见区域时请求，最多同时请求四张；生成中的预览最多自动重试三次，失败后显示具体原因与手动重试入口。

照片、收藏、相册、回收站和相册选图支持文件名包含搜索、拍摄日期范围、静态/动态照片及 JPEG/PNG/HEIC 类型筛选，可切换最新/最早在前。搜索覆盖当前视图的完整图库，并非只查找已加载照片；文件名中的 `%`、`_` 和反斜杠按字面匹配。日期按浏览器本地时区解释，包含结束日期当天；回收站仍按删除时间排序，日期筛选始终针对拍摄时间。点击“查找”应用条件，“重置”恢复全部条件及默认排序，切换条件会清空旧选择。照片墙可选择或取消当天已加载照片，每批上限仍为 1000 项。

大图支持上一张/下一张、列表边缘自动补页、键盘方向键、触摸左右切换、详情、收藏、加入相册和原件下载。照片信息包含名称、时间、格式、大小、尺寸、时间来源及可读取的 EXIF 相机/镜头/拍摄参数/GPS。可编辑描述、位置及拍摄时间，选择栏支持批量时间修正。说明见 [照片资料与时间修正](web-photo-metadata.md)。列表选择只作用于已加载项目，每批最多 1000 项并显示数量。

相册支持创建、改名/描述、添加/移除照片、设置封面和删除相册；删除相册不删除照片。回收站支持所选/全部恢复及所选永久删除/清空；全量动作明确包含尚未加载的回收项，永久删除独立确认。永久删除提交成功表示逻辑删除已提交，物理清理由现有持久任务继续，不把提交响应当作 R2 清理完成。

JPEG、PNG、HEIC 均按需生成 256/2048 JPEG 衍生图，原件不重编码。Live Photo 只展示照片主体，隐藏配套 MOV；可手动调用已有播放接口，浏览器不能解码时明确提示并提供照片和 MOV 分别下载。分别下载不等于恢复成 iPhone 系统 Live Photo。

相册页支持名称/描述搜索和四种排序，选择栏与大图支持批量复制/移动到其他相册，大图另有快捷封面入口。规则与事务边界见[相册整理](web-albums.md)。

新增[照片归档管理](web-photo-archive.md)：大图和选择栏可归档/取消归档，独立归档列表复用筛选、排序和时间线；相册、收藏、分享与原件保留。

新增[照片标签与评分](web-photo-labels.md)，大图和选择栏支持设置，查找表单支持标签精确匹配及评分组合筛选；同步、数据保持与范围边界见说明。

新增[回忆 / 往年今日](web-memories.md)：按当前时区汇总往年同一天，支持参考日期、年份封面与数量、年份内完整浏览和照片管理；排除归档和回收站。

## 时间线浏览

照片、收藏和个人相册提供年月导航。桌面右侧显示年份和有照片的月份，手机通过「跳转日期」打开年月面板。月份统计使用当前筛选和浏览器 IANA 时区，选中月份后直接读取该月附近的照片，继续滚动可查看前后月份。

滚动接近列表上下边缘时自动补页，也可使用加载按钮。顶部补页保留当前可见照片的位置，日期标题吸顶并避开批量选择栏。月份跳转保留选择，改变筛选条件会清空选择。大图翻到已加载列表边界时补取相邻照片。

同一标签页会记录账号、浏览历史条目、筛选、排序和可见照片位置。关闭大图、页面返回、浏览器后退和刷新后恢复位置。页面重新获得焦点时先检查图库版本，版本变化后围绕原位置刷新。定位照片已删除或不再符合筛选时，使用最近的有效照片。退出或账号会话失效时清除浏览记录。

列表接口新增 `anchorTime` 和可选 `anchorId` 用于定位，不能与 `cursor` 同时提供。返回 `previousCursor/nextCursor`，照片始终保持所选排序。新增 `GET /api/immich-cf/web/timeline` 接受相同视图、相册和筛选参数，另接收 `timeZone`，返回 `version/months`。每月包含年月、数量和定位锚点。携带相同 `version` 可取得 `unchanged` 响应。年月概览读取轻量日期字段，浏览位置只保留定位信息。

## 浏览器上传

顶部“上传”打开本页队列，支持拖拽、多选、逐项进度、停止/继续和失败重试。每批最多 100 个逻辑项目；照片和配套 MOV 合为一项。队列顺序上传，成功和重复分别计数，不因单项格式错误阻止后续有效文件；网络、会话、配额、限流和服务故障会暂停队列，保留未开始项目。完成后刷新图库及用量。在个人相册内打开上传，会先保存原件再加入当前相册；相册操作失败会明确说明“照片已保存”，重试只补相册关系。

实际格式、大小和像素限制来自 bootstrap：当前支持 JPEG/PNG/HEIC（含符合容器要求的 HEIF），照片最多 20,000,000 字节、6400 万像素、单边 16384；配对 MOV 最多 64 MiB。浏览器先检查扩展名、空文件、名称和字节大小，服务端继续验证真实容器、尺寸、配对元数据、校验和、权限及名额。原始字节不压缩，提交 SHA-1；新上传优先采用原件 EXIF 拍摄时间和偏移，无偏移时按浏览器时区解释，无有效原件时间时回退到文件修改时间。

Live Photo 须同时选择一张照片及一份同名 MOV（忽略扩展名和大小写）。文件名仅用于建议配对，服务端核对内嵌标识；先保存 MOV 再提交照片。独立视频、缺少配套原件、同名歧义及不匹配的配对明确拒绝。已确认的动态 ID 保留在本页队列，失败重试复用；失败/停止后的动态原件与暂存依照现有保留和过期清理规则处理，不将部分上传称作完整备份。

进度 100% 仅表示请求发送完成，须等待服务端返回 created/duplicate 才确认结果。停止或网络中断时，当前文件可能已提交；重新上传相同内容由服务端去重，不重复消耗逻辑资产名额。回收站内的相同文件会显示“已存在”。队列仅保留在当前页面内，关闭上传面板、刷新或退出登录后需重新选择原件；不提供跨刷新续传或分块上传。清空队列不删除已保存原件。

上传入口为 POST `/api/immich-cf/web/upload`，严格要求同源 Origin 与有效 Cookie/Bearer 会话，直接复用原有上传与存储流程，不另建资产或授权模型。表单和错误不写入应用日志，错误保留具体字段与修正要求。新入口不改变官方 App 的 `/api/assets` 契约。

## 批量下载

照片、收藏、相册或回收站中选择项目后，点击“打包下载”；每次支持 1～1000 张照片。个人相册详情的“下载整本相册”包含整本相册所有有效照片，包括未加载及被当前筛选隐藏的项目，排除回收站项目，最多 10,000 张。下载前显示照片数、原件数、原件总字节和 ZIP 分包清单。

每个 ZIP 最多包含 1 GiB 原件或 1000 份文件；同组 Live Photo 的照片与 MOV 使用共同名称、始终放在同一包。保留原始字节，不转码或重新压缩照片；中文名称保留，跨包重名自动编号，路径和系统保留字符会清理。ZIP 包含原件，不包含相册关系、收藏或完整账号元数据，不能代替账号备份与系统 Live Photo 恢复。

可逐包点击“下载 ZIP”或“依次下载全部”，浏览器可能要求允许多个文件下载。面板显示按原件处理的进度与服务端传输结果；文件是否保存成功仍以浏览器下载列表为准。“停止后续分包”或关闭面板停止后续任务，当前文件须在浏览器下载列表取消。失败的 ZIP 应重新下载，不提供断点续传。

任务只绑定当前账号及当前登录会话，24 小时后失效；每账号最多保留 2000 个未过期分包，现有维护调度分批清除过期清单。准备及逐份读取时检查会话和图库版本，图库/相册变化、登录撤销、原件缺失或摘要不符会明确失败，需重新准备。ZIP 在服务端逐份流式生成，不写入 R2，不将整个 ZIP 缓存在浏览器内存。逐份校验原件长度与 SHA-1，最后校验通过才输出 ZIP 尾部，避免把不完整归档称作成功。

## 照片分享

在照片、收藏或相册中选择 1～1000 张照片，点击「分享所选」。要分享整本相册，在相册详情点击「分享整本相册」。整本相册链接覆盖当前筛选隐藏和尚未加载的照片，添加和移除成员会同步改变访客可见的照片范围。回收站照片不可分享。

链接有效期可选 1 天、7 天或 30 天，默认 7 天。创建时可开启「设置访问密码」和「允许下载原件」。两项默认关闭，已有链接也可以在「分享管理」中编辑权限。密码至少 8 个字符，UTF-8 编码后最多 72 字节。完整链接在生成时复制，访问密码可另行告知访客。

访客无需登录账号。有密码的链接需要先解锁，再查看照片和大图预览。允许下载时，大图提供照片原件和配套 Live Photo MOV 的下载按钮。更换密码会让已有解锁失效，关闭下载即时限制后续原件请求。分享管理支持清除密码或撤销整条链接。

密码保存为 bcrypt 摘要。每条链接一分钟内最多验证 5 次密码。解锁凭据最长有效 4 小时且受链接到期时间限制，浏览器仅在当前页面内保留。链接的访问凭据位于 URL 片段，访客通过 Authorization 头发送凭据，服务端只存 SHA-256 摘要。每次读取都会检查链接和照片范围，撤销、删除相册或停用账号会使对应链接失效。每账号最多 100 个有效链接，维护调度分批清理过期记录。

## 账号与权限

- 普通用户只访问自己的照片与相册。网页不增加管理员跨账号照片浏览能力；原有受控运维导出接口保持原权限。
- 管理员沿用 `operations_admins` 显式授权，与官方 App 的 `isAdmin` 区分；网页不能授予管理员权限，也不能管理其他运维管理员。
- 管理普通账号：分页/按名称和邮箱查询，创建、修改显示名称、停用/启用、重置密码、撤销全部会话。登录邮箱创建后不可修改，不提供删除账号。
- 新密码至少 15 个字符、UTF-8 编码后最多 72 字节，使用现有 bcrypt cost 12；登录兼容既有密码，不改旧账号哈希。
- 自行修改密码须验证旧密码；修改/重置密码、停用账号均撤销全部会话。启用后必须重新登录。照片、相册与原件保留。
- 新账号管理写操作严格校验同源；在同一 D1 事务中重新检查有效会话、运维授权及目标账号权限。自行改密还复核验证时的密码哈希，防止并发修改覆盖。
- 成功管理动作记录操作者 ID、目标 ID、动作和时间；事务失败连同审计一起回滚。密码、哈希、令牌和表单提交值不进入管理审计或应用错误日志。
- 表单错误保留结构化 `errors[].path/message`，前端展示具体字段、原因和修正要求，不以泛化提示覆盖具体原因，不回显敏感值。

账号页和管理页显示逻辑资产名额、动态上限、原件逻辑字节和回收项；名额包含回收站与待完成预约，原件逻辑字节包含回收站，不称作 R2 物理占用或账单。

## 新增接口

所有接口响应 `Cache-Control: no-store`。登录功能使用现有会话。访客接口使用分享链接的独立访问凭据。

| 接口                                                   | 行为                                                                                                        |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| GET `/api/immich-cf/web/bootstrap`                     | 当前用户、网页管理权限、用量和服务端有效限制                                                                |
| POST `/api/immich-cf/web/upload`                       | 同源 multipart 上传；原件校验、去重、Live Photo 配对和名额规则复用官方 App 上传流程                         |
| GET `/api/immich-cf/web/assets`                        | `view=photos/archive/library/favorites/trash/album`；相册视图必填 `albumId`；支持 `limit/cursor` 和下述筛选 |
| GET `/api/immich-cf/web/timeline`                      | 照片、收藏或相册的月份数量与定位锚点；支持同样筛选及 `timeZone/version`                                     |
| GET `/api/immich-cf/web/assets/{id}/metadata`          | 本人照片的 EXIF、手动资料、时间来源和版本                                                                   |
| POST `/api/immich-cf/web/assets/{id}/metadata/extract` | 同源提交版本，从原件读取资料；保留手动覆盖和已有拍摄时间                                                    |
| PATCH `/api/immich-cf/web/photo-metadata`              | 同源提交所选照片、版本和资料修改；支持绝对时间或整体分钟偏移                                                |
| GET/HEAD `/api/immich-cf/web/assets/{id}/preview`      | `size=thumbnail/preview`，只返回衍生图；生成中/失败/额度不足返回具体 503                                    |
| GET/HEAD `/api/immich-cf/web/assets/{id}/download`     | `component=photo/motion`，保留原始字节，安全 attachment 文件名                                              |
| POST `/api/immich-cf/web/downloads`                    | 同源 JSON，`ids` 或 `albumId` 二选一；返回当前会话专属分包计划和限制                                        |
| GET/DELETE `/api/immich-cf/web/downloads/{id}`         | 查询传输状态与进度；同源 DELETE 停止任务                                                                    |
| GET `/api/immich-cf/web/downloads/{id}/archive`        | `attempt` 为 UUID；流式原件 ZIP、明确长度、附件响应，失败可重试                                             |
| GET/POST `/api/immich-cf/web/shares`                   | 列出本人有效链接，或同源提交 `ids` / `albumId` 与 `days` 创建链接                                           |
| PATCH/DELETE `/api/immich-cf/web/shares/{id}`          | 同源更新本人的 `password`、`allowDownload` 或撤销链接                                                       |
| POST `/api/immich-cf/web/shared/unlock`                | 使用 `Authorization: Share …` 提交访问密码，返回临时解锁凭据                                                |
| GET `/api/immich-cf/web/shared`                        | 使用 `Authorization: Share …` 读取访客照片列表，支持 `cursor/limit`                                         |
| GET `/api/immich-cf/web/shared/assets/{id}/preview`    | 使用分享凭据读取授权预览，支持 `size=thumbnail/preview`                                                     |
| GET `/api/immich-cf/web/shared/assets/{id}/download`   | 下载已授权照片或配套 MOV，支持 `component=photo/motion`                                                     |
| POST `/api/immich-cf/web/password`                     | `currentPassword/newPassword`，成功后清除 Cookie 并撤销全部会话                                             |
| GET/POST `/api/immich-cf/admin/users`                  | 分页账号列表（`q/limit/cursor`）；创建字段 `email/name/password`                                            |
| PATCH `/api/immich-cf/admin/users/{id}`                | 每次只改 `name` 或布尔值 `disabled`                                                                         |
| POST `/api/immich-cf/admin/users/{id}/reset-password`  | `password`，撤销目标全部会话                                                                                |
| DELETE `/api/immich-cf/admin/users/{id}/sessions`      | 撤销普通账号全部会话                                                                                        |

照片筛选参数：`q` 为去除首尾空白后最多 100 字符的文件名片段（ASCII 字母不区分大小写）；`from/to` 为规范 UTC ISO 时间（如 `2026-11-01T16:00:00.000Z`），分别为包含/不包含的拍摄时间边界；`type=all/static/live/jpeg/png/heic`；`order=newest/oldest`。筛选字段不得重复，日期和范围错误返回明确字段及修正要求。前后端共用参数校验规则，不回显错误提交值。

照片分页返回 `items/previousCursor/nextCursor/version`，游标绑定当前账号、视图、相册、全部筛选/排序条件和资产/相册版本，按时间与 ID 继续读取；切换条件使用旧游标返回 400，图库变化返回 409。时间线围绕当前可见照片重新定位；网络失败保留照片并提供重试。账号列表返回 `items/nextCursor`，按账号 ID 稳定分页。收藏、相册、回收站和会话操作复用既有接口及同步日志，不建立另一份图库数据。回收站的“全部恢复”和“清空”始终覆盖全部回收项（包括筛选未显示和未加载项目），确认框明确说明范围。

## 本地开发、构建与发布

大图支持缩放拖动、双击缩放、系统全屏和幻灯片，图库与相册选图面板支持 Shift 区间选择；操作与边界见[大图浏览与连续选择](web-viewer.md)。

前端为 React + TypeScript + Vite，静态产物位于忽略目录 `dist/web`，与 Worker 同源提供。Worker 优先路由；`/api`、发现与健康检查始终进入后端，未知路径不返回伪成功 HTML。HTML 不缓存，带指纹静态文件缓存一年；私有数据和媒体不缓存。网页设置 CSP、禁止框架嵌入与 MIME 嗅探。

```sh
pnpm install --frozen-lockfile
pnpm db:migrate:local
pnpm dev:local
```

打开 `http://127.0.0.1:8787/`。`dev:local` 使用隔离本机存储；原有 `pnpm dev` 仍连接真实 dev D1/R2。需要热更新时，同时运行 `pnpm web:dev`，其 `/api` 代理到 8787；需要验证与发布一致的同源/静态路由行为时使用 8787 构建预览。

发布流程要求干净提交并从同一提交重新构建网页，再应用前向迁移和部署。迁移 0030 新增日期索引、账号事务守卫与管理审计，并扩展原有预览归属检查支持 JPEG/PNG；不重建或清空现有数据。Images 沿用已有免费额度、租约与熔断，不购买或升级服务。

迁移 0031 只新增有界、可过期的网页下载任务表与索引，不复制或修改现有媒体。ZIP 使用固定版本 `client-zip` 2.5.1，配合 Workers `FixedLengthStream` 发送准确长度，运行时逐份读取 R2 原件。

迁移 0032 新增 Web 分享链接表、数量限制和账号停用时的撤销触发器。访客复用现有 JPEG 衍生预览，照片和相册的同步接口继续沿用冻结契约。

迁移 0033 为已有链接补上默认权限，并增加临时解锁凭据、密码尝试限制和密码变更时的失效处理。
