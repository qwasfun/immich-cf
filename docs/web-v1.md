# 网页版 V1：需求、使用与接口

## 产品范围

中文、适配电脑与手机的私人图库，复用官方 App 使用的账号和数据。导航包含照片、收藏、个人相册、回收站、账号设置；运维管理员额外看到账号管理。第一版不提供浏览器上传、公开注册、分享、照片编辑、地图、人脸识别或视频转码。

网页地址为 dev Worker 根地址：<https://immich-cf-api-dev.fun.workers.dev/>。首次进入使用已有邮箱和密码登录；刷新页面保持 Cookie 会话，退出后不再访问私有媒体。App 服务器地址保持根地址不变。

照片墙按拍摄时刻倒序、相同时按 ID 排序，并按浏览器本地日期分组；回收站按删除时刻排列。每页默认 60 项、最多 100 项，手动加载下一页，不在首屏读取整库。缩略图仅在接近可见区域时请求，最多同时请求四张；生成中的预览最多自动重试三次，失败后显示具体原因与手动重试入口。

大图支持上一张/下一张已加载照片、键盘方向键、触摸左右切换、详情、收藏、加入相册和原件下载。照片信息包含名称、时间、格式、大小和尺寸。列表选择只作用于已加载项目，每批最多 1000 项并显示数量。

相册支持创建、改名/描述、添加/移除照片、设置封面和删除相册；删除相册不删除照片。回收站支持所选/全部恢复及所选永久删除/清空；全量动作明确包含尚未加载的回收项，永久删除独立确认。永久删除提交成功表示逻辑删除已提交，物理清理由现有持久任务继续，不把提交响应当作 R2 清理完成。

JPEG、PNG、HEIC 均按需生成 256/2048 JPEG 衍生图，原件不重编码。Live Photo 只展示照片主体，隐藏配套 MOV；可手动调用已有播放接口，浏览器不能解码时明确提示并提供照片和 MOV 分别下载。分别下载不等于恢复成 iPhone 系统 Live Photo。

## 账号与权限

- 普通用户只访问自己的照片与相册。网页不增加管理员跨账号照片浏览能力；原有受控运维导出接口保持原权限。
- 管理员沿用 `operations_admins` 显式授权，与官方 App 的 `isAdmin` 区分；网页不能授予管理员权限，也不能管理其他运维管理员。
- 管理普通账号：分页/按名称和邮箱查询，创建、修改显示名称、停用/启用、重置密码、撤销全部会话。登录邮箱创建后不可修改，不提供删除账号。
- 新密码至少 15 个字符、UTF-8 编码后最多 72 字节，使用现有 bcrypt cost 12；登录兼容既有密码，不改旧账号哈希。
- 自行修改密码须验证旧密码；修改/重置密码、停用账号均撤销全部会话。启用后必须重新登录。照片、相册与原件保留。
- 新账号管理写操作严格校验同源；在同一 D1 事务中重新检查有效会话、运维授权及目标账号权限。自行改密还复核验证时的密码哈希，防止并发修改覆盖。
- 成功管理动作记录操作者 ID、目标 ID、动作和时间；事务失败连同审计一起回滚。密码、哈希、令牌和表单提交值不进入管理审计或应用错误日志。
- 表单错误保留结构化 `errors[].path/message`，前端展示具体字段、原因和修正要求，不以泛化提示覆盖具体原因，不回显敏感值。

账号页和管理页显示逻辑资产名额、动态上限、原件逻辑字节和回收项；名额包含回收站与待完成预约，原件逻辑字节包含回收站，不称作 R2 物理占用或账单。

## 新增接口

所有接口复用现有会话，响应 `Cache-Control: no-store`；无需在 URL 或网页持久存储中放置访问令牌。

| 接口                                                  | 行为                                                                             |
| ----------------------------------------------------- | -------------------------------------------------------------------------------- |
| GET `/api/immich-cf/web/bootstrap`                    | 当前用户、网页管理权限、用量和服务端有效限制                                     |
| GET `/api/immich-cf/web/assets`                       | `view=photos/favorites/trash/album`；相册视图必填 `albumId`；支持 `limit/cursor` |
| GET/HEAD `/api/immich-cf/web/assets/{id}/preview`     | `size=thumbnail/preview`，只返回衍生图；生成中/失败/额度不足返回具体 503         |
| GET/HEAD `/api/immich-cf/web/assets/{id}/download`    | `component=photo/motion`，保留原始字节，安全 attachment 文件名                   |
| POST `/api/immich-cf/web/password`                    | `currentPassword/newPassword`，成功后清除 Cookie 并撤销全部会话                  |
| GET/POST `/api/immich-cf/admin/users`                 | 分页账号列表（`q/limit/cursor`）；创建字段 `email/name/password`                 |
| PATCH `/api/immich-cf/admin/users/{id}`               | 每次只改 `name` 或布尔值 `disabled`                                              |
| POST `/api/immich-cf/admin/users/{id}/reset-password` | `password`，撤销目标全部会话                                                     |
| DELETE `/api/immich-cf/admin/users/{id}/sessions`     | 撤销普通账号全部会话                                                             |

照片分页返回 `items/nextCursor/version`，游标绑定当前账号、视图、相册和资产/相册版本，按时间与 ID 继续读取；图库变化返回 409，界面保留原因并提供从第一页刷新的入口。账号列表返回 `items/nextCursor`，按账号 ID 稳定分页。收藏、相册、回收站和会话操作复用既有接口及同步日志，不建立另一份图库数据。

## 本地开发、构建与发布

前端为 React + TypeScript + Vite，静态产物位于忽略目录 `dist/web`，与 Worker 同源提供。Worker 优先路由；`/api`、发现与健康检查始终进入后端，未知路径不返回伪成功 HTML。HTML 不缓存，带指纹静态文件缓存一年；私有数据和媒体不缓存。网页设置 CSP、禁止框架嵌入与 MIME 嗅探。

```sh
pnpm install --frozen-lockfile
pnpm db:migrate:local
pnpm dev:local
```

打开 `http://127.0.0.1:8787/`。`dev:local` 使用隔离本机存储；原有 `pnpm dev` 仍连接真实 dev D1/R2。需要热更新时，同时运行 `pnpm web:dev`，其 `/api` 代理到 8787；需要验证与发布一致的同源/静态路由行为时使用 8787 构建预览。

```sh
pnpm check
pnpm contracts:verify
pnpm release:dev
```

发布流程要求干净提交并从同一提交重新构建网页，再应用前向迁移和部署。迁移 0030 新增日期索引、账号事务守卫与管理审计，并扩展原有预览归属检查支持 JPEG/PNG；不重建或清空现有数据。Images 沿用已有免费额度、租约与熔断，不购买或升级服务。

验收包括至少 1000 个合成逻辑资产、分页隔离/变化、原件摘要、预览故障/额度、Live Photo、管理员提交竞态、会话撤销、桌面与手机宽度交互。真实 iPhone Safari、设备解码与系统相册恢复独立记录，不用桌面模拟替代。部署结果见 [dev 验收记录](web-v1-dev-deployment.md)。
