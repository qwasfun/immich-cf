# P2 高像素原图异常恢复

日期：2026-10-18，dev 分支本机开发。优先补齐高像素上传/读取与同步状态边界的回归及可重复公网探针；未发现需要修改业务状态机的问题，本轮业务 Worker 代码不变。CPU 超预算继续暂缓，真实图库、官方 iOS 与 G1 不因此通过。

## 状态与恢复边界

- R2 写前失败：保留同一预约，无已发布资产；写后响应丢失：同一预约和私有对象键可重用；D1 提交后响应丢失：同一资产已发布，重传返回 duplicate。高像素文件仍先经过字节、容器和安全元数据检查。
- 重启进程后仍从持久 D1/R2 状态恢复；并发同体重传最终只保留一份资产和原图，不产生额外预约，布局尺寸与 EXIF 宽高交换不丢失。
- 已发布原图缺失或原生 SHA-1 不符时，私有读取返回 503，不误报 304；完整同图并发重传修复对象，不改变资产行、ID、尺寸或同步游标。没有自动删除历史原图、源引用或预约。
- reset 快照生成后才完成的上传恢复必须留在后续增量；已暂停的旧 ACK 在 reset 后返回 409，不允许提交旧检查点。ACK 新快照后，新增高像素资产仍准确投递一次，再 ACK 才回到空增量。
- multipart 截断和流读取错误没有资产/预约副作用；错误定位 assetData，完整同体重传可继续。永久 400/409/413 不进入传输重试。

## 回归素材与范围

新增 tests/fixtures/large-images.mjs 用逐行流式压缩构造实际编码的 **8064×6048、48,771,072 像素 RGB PNG**；每行固定数据，不读取私人照片，不在 Worker 内生成或解码像素。JPEG 路径另使用明确标注的仅改图片头结构变体，不能将后者当作真实可解码大 JPEG 黄金样本。

四组集成回归覆盖 R2 前后/D1 后失败、一次 Worker 重启、并发重传、multipart 截断与读错误、缺失/等长损坏原图修复、reset/ACK 确定性交错。实际编码 PNG 同时覆盖 EXIF 方向 6（同步布局为 6048×8064），并核对原图和当前原图式预览字节、资产/预约/对象计数、完整快照与 ACK 后空增量。

测试故障注入仍只在 tests/fixtures/fault-worker.ts 的本机入口，发布入口仍为 src/index.ts，不向生产加入注入接口或故障 header 支持。所有已有 Live Photo、XMP、4 MiB 精确边界、密码与会话、reset/ACK 隔离回归继续执行。

## 可重复 dev 公网探针

```powershell
node scripts/large-pixel-recovery-probe.mjs
```

固定 dev 地址与已验证的本机代理 http://127.0.0.1:7890，TLS 1.2 且保持证书校验；从本机忽略文件 work/dev-pixel-account.json 读取独立验收账户。该账户仍最多 20 张，不读取私人图片清单，不提高额度，不清理已有测试或用户资产。需要已部署 dev、该凭据文件与现有代理可用。

只生成固定灰色高像素 PNG，并构造截断请求、Live Photo EXIF 拒绝项、超过 4 MiB 项，以及完整原图和精确 4 MiB 的可解码 PNG。精确边界通过插入合法 tEXt 块填充实际编码图片，保持真实像素流；区别于上一轮仅改尺寸头的协议样本。正常两项均应重传返回同 ID，原图/当前预览 Range 逐字节相等，reset:true 投递尺寸准确，ACK 后增量为空且退出成功。

上传复用 retryCurlUpload（最多 3 次、总预算 120 秒、同体与 checksum）；回读复用 readCurlRanges（512 KiB 分段、稳定 ETag/准确 Content-Range、每段最多 3 次、总预算 180 秒）；JSON 最多 3 次、单次 20 秒、总预算 60 秒，仅现有瞬时传输错误或 502/503/504 重试。网络间歇性错误记录为传输现象，不直接归因业务缺陷。报告写入 work/large-pixel-recovery-dev-probe.json，不包含密码、令牌、账户或资产 ID。

该公网探针不注入 R2/D1 故障，也不故意篡改线上原图；存储故障、进程重启和并发交错的异常证明来自本机隔离回归。成功 HTTP 顺序不等同官方 App 自动备份调度，手机仍按[真机步骤与模板](p2-image-limits-ios.md)验证。

6400 万像素/单边 16384、4 MiB、Live Photo 防护、bcrypt cost 12、现有 reset/ACK epoch/事务隔离均不降低，官方 App 不修改；CPU 超预算不采样也不改为通过。
