# 网页版 V1 dev 验收记录

2026-11-02（Asia/Shanghai）。本轮只发布 dev，不晋升 test/生产。需求、接口与使用说明见 [网页版 V1](web-v1.md)。

## 本机验证

- 完整检查：236 项本机测试通过，0 失败、0 跳过；格式、代码规范、前后端类型与 Worker/网页构建通过。
- 新增 9 组 Worker/D1/R2 集成场景：1001 张合成照片跨日期分页与筛选、游标归属与版本冲突；JPEG/PNG/HEIC 预览/原件、额度和故障；Live Photo 隐藏组件/下载/回收恢复；账号字段校验、角色隔离、密码与会话撤销；提交前管理员撤权时原子回滚。
- 浏览器本机隔离账号与公开样本：已验证登录、照片墙、大图、详情、收藏、移入回收站和恢复，相册创建/添加照片/设置封面，以及账号用量、会话和管理表单；空名称显示具体字段错误。桌面 1280px、手机 390px 无横向溢出，手机显示双列照片与折叠导航。
- 本机预览素材来自此前固定公开样本的 JPEG 预览，未使用用户私人图库做浏览器演练。

浏览器补充验收、dev Worker 版本、公网接口结果和既有数据保护结果在发布后追加。当前记录不能作为真实 iPhone Safari、视频解码或系统 Live Photo 恢复验收通过的证据。
