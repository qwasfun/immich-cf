## Linux CI 传输修正

首次远端检查中，网页版 9 组集成用例通过，但两组既有 P1 用例遇到开发代理的 `Network connection lost`：应用拒绝超限 JSON 或无效 multipart 并取消输入流后，代理的后续连接返回 500。针对这些表单校验用例，在测试入口先接收完本机 HTTP 输入，再将相同字节交给真实应用解析器；原有流式/中断用例继续使用各自的注入流，校验规则与状态断言均不放宽。

字段校验、Cookie/Bearer/会话与 multipart 边界共 3 项定向复测通过。此次修正仅涉及测试入口，不改变已发布 Worker 或用户数据。
