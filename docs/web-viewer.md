# Web 大图浏览与连续选择

适用于照片、收藏、个人相册和回收站的大图，分享访客页也复用相同的静态照片浏览控件。

## 大图操作

- 双击照片在适应窗口和 200% 之间切换；按钮、鼠标滚轮及 `+` / `-` 可在 100%–400% 范围缩放。100% 表示适应窗口，放大的是现有预览图。
- 放大后按住鼠标拖动，或用方向键移动；图片边缘受限，较短的轴保持居中。按 `0` 或“适应窗口”复位，翻页也会复位。
- 触摸屏支持双击、双指缩放与放大后拖动；适应窗口时左右滑动翻页。翻页按钮始终可用。
- 方向键在适应窗口时翻页，放大后移动照片；`PageUp` / `PageDown` 始终翻页。输入框、下拉框及其他弹窗保留自己的键盘行为。
- “全屏”或 `F` 进入/退出浏览器系统全屏。浏览器不支持或拒绝时显示原因，仍可浏览窗口大图。`Escape` 优先复位缩放，再退出全屏、关闭大图；浏览器可能先处理系统全屏的 Escape。
- 关闭大图沿用时间线原有的位置恢复。加载相邻页面期间关闭大图，不会被稍后返回的请求重新打开。

## 幻灯片

默认每张 5 秒，可选择 3 秒或 10 秒；按当前筛选及排序向后播放，预览加载完成后计时，列表边缘自动读取下一页。最后一张停止，不循环。照片、相册和分享页都支持。

手动翻页、缩放、拖动、打开资料或其他操作、切换窗口、隐藏标签页、加载失败和播放动态视频时暂停，回到窗口后手动继续。播放 Live Photo 时使用静态预览，仍可手动播放原有动态视频。系统全屏切换也暂停；进入全屏后可再次启动幻灯片。空格可开始/暂停，但焦点位于按钮时保留按钮自身行为。

网络错误保留当前照片与列表，提供重试；分享页沿用访问密码、到期和下载权限校验。缩放和幻灯片只请求衍生预览，不请求原件；允许下载的访客仍需主动点击下载。

## Shift 连续选择

先点击一张照片的选择按钮作为锚点，再按住 Shift 点击另一张照片或其选择按钮，处理当前显示顺序中两者之间的已加载照片（包含两端）。目标未选时增选整个区间；目标已选时取消该区间；区间外选择保留。选择按钮也支持 Shift 加键盘激活。

区间锚点使用照片 ID，向前或向后补页后仍有效。月份跳转保留选择；锚点不在已加载列表时，按单张选择并建立新锚点。改变筛选、排序或账号、取消全部选择后清除锚点。按天选择和选择全部已加载项目沿用原有操作。相册添加照片面板也支持 Shift。

单次最多选择 1000 张。超过上限时完整保留原选择并提示“所选照片：每次最多 1000 项，请先取消部分选择或缩小区间”，不会部分选中。

## 验证边界

本轮仅扩展 Web 客户端，无数据库迁移或新增接口。几何与选择单元测试覆盖纵横图、边界拖动、焦点缩放、倒序、补页后的锚点、缺失锚点及 1001 张越界。浏览器交互、公网发布与真实设备结果分别记录；桌面触摸模拟不能替代真实 iPhone Safari 的手势与全屏验收。
