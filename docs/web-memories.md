# Web 回忆 / 往年今日

侧栏“往年今日”按浏览器当前时区显示往年同一天的照片，按年份展示封面、距今年数和照片数量。可以选择今天或之前的参考日期、切换前后一天、回到今天，再进入任一年份回看该天的完整照片。

参考日期的年份是上限，例如选择 2026-01-01，只包含当地拍摄日在往年 1 月 1 日的照片，不包含 2026 年及之后的照片。选择 2024-02-29 时只匹配此前闰年的 2 月 29 日，不将非闰年的 2 月 28 日或 3 月 1 日替代为闰日。归档、回收站、隐藏的配套 MOV 及其他账号照片不进入回忆；Live Photo 按照片主体计一张。

年份详情复用现有照片网格、文件名/类型/标签/评分/日期筛选、排序、60 张双向自动分页、Shift 选择、大图缩放/幻灯片及收藏、相册、分享、下载、标签评分、时间修正、归档和删除操作。筛选在该年该天范围内继续取交集，不能扩展到其他日期。修改照片时间、归档或删除后，回忆数量和范围随图库版本更新。

参考日期和年份写入页面路径，支持刷新和直接打开；年份内浏览位置与筛选沿用按账号、浏览历史条目及日期/年份/时区区分的时间线记录。返回大图、页面返回及刷新保持位置；账号退出清除。默认“今天”每分钟及重新获得焦点时检查当地日期，跨午夜后更新；手动选择的日期保持。

## Web 接口

- `GET /api/immich-cf/web/memories?memoryDate=YYYY-MM-DD&timeZone=IANA` 返回参考日期、时区、图库版本、总数量及年份列表（年份、距参考年数、数量、封面照片 ID）。省略日期时使用该时区今天，省略时区使用 UTC。只查询当前账号有效未归档照片的 ID 和拍摄时间，在服务端按指定时区聚合。可传相同范围已知的 `version` 请求未变化响应。
- 现有 `/web/assets` 和 `/web/timeline` 增加 `view=memories&memoryDate=YYYY-MM-DD&memoryYear=YYYY&timeZone=IANA` 范围；年份必须早于参考年份且存在该日。筛选、锚点和双向分页规则保持，游标同时绑定账号、年份、参考日期、时区、筛选、排序与图库版本。
- 按当地日界产生 UTC 时间区间，处理夏令时 23/25 小时、重复小时、午夜跳时及整日跳过；不以固定 24 小时或 UTC 的月日匹配当地日期。

接口只读、需有效登录、响应不缓存，不返回对象键、文件名清单或凭据。输入错误保留字段名称、原因与修正要求。读取完成前复核会话；详情继续复用既有照片归属和版本检查。本轮无需迁移，不改官方 App 契约、不写回原件，也不保存一份独立的回忆副本。

不提供 AI 主题回忆、人脸识别、手动编辑回忆集合或官方 App Memories API/同步；本轮是 Web 往年今日入口。真机 iPhone Safari、系统 Live Photo 恢复及完整灾备仍为独立验收项。
